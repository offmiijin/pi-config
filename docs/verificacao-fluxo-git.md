# Verificação do fluxo Git

Nota criada para validar o fluxo de trabalho do repositório:

1. criar branch de trabalho (`test/verificacao-fluxo-push`);
2. commit seguindo Conventional Commits em PT-BR;
3. `git push` da branch para `origin`.

Este arquivo pode ser removido junto com a branch após a verificação.

Push verificado via ssh-agent (sem chave privada no sandbox).
